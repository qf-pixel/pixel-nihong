# 霓虹像素夜校 · 小学算术练习

> 项目代号：`kids-math-practice` ｜ 界面名：PIXEL MATH / 霓虹像素夜校
> 技术栈：Spring Boot 3.1.5 + Thymeleaf + MyBatis + MySQL 8 ｜ 运行环境：JDK 17
> 文档日期：2026-11-18（按当前随包 JAR 的实际行为整理）

一个给小学生练口算的网页系统。学生端是霓虹街机风的答题游戏，家长端负责绑定学生、布置练习任务、查看正确率与薄弱运算。界面文案按 1–3 年级低龄场景设计，账号注册支持 1–6 年级。

## 1. 项目解决什么问题

口算能力靠**高频、短时、有反馈**的练习，但家庭场景里通常有三个麻烦：

1. **孩子不愿意练**：纸质口算本枯燥，写一页要很久，错了也没有即时反馈。
2. **家长没精力出题和批改**：每天手动出题、对答案、记录错题，很难坚持。
3. **练完没有沉淀**：今天错的题，明天还是错；家长也说不清孩子到底哪类运算薄弱。

本项目把一次 5 分钟口算包装成一场街机闯关：

- 学生端：选运算、选难度、选题量，进入跑酷答题页；每道题即时显示对错，全部答完给出正确率和用时，答错的题自动进入错题本。
- 家长端：用 6 位绑定码绑定孩子，按运算/难度/题量/数值范围布置任务，可设截止时刻；孩子完成后能看到每次练习的正确率、用时和 7 天 / 30 天的分运算分析。

**适用场景**：家庭一台电脑或局域网内使用、课堂演示。**不面向公网运营**。

## 2. 主要功能

### 2.1 学生端（登录后进入「大厅」）

| 功能 | 说明 |
|---|---|
| 注册 / 登录 | 11 位手机号 + 6–64 位密码；密码 BCrypt 哈希存储；注册时角色固定为学生或家长 |
| 自主练习 | 从大厅点「开始练习」，进入练习设置页 |
| 练习设置 | 运算模式：混合 / 加法 / 减法 / 乘法 / 除法；难度：L1 基础 / L2 进阶 / L3 挑战；题数 5–100；数值范围 20 / 50 / 100 |
| 答题页 | 顶部跑酷场景 + 超大题目 + 计时；可用输入框键入答案，也可点屏幕数字键盘；只接受 1–3 位数字 |
| 判分与推进 | 输入后页面先做一次即时反馈，1000 ms 后提交表单；**最终对错由服务端判分**，前端反馈不作为成绩依据 |
| 结果页 | 显示答对数 / 总题数、用时、正确率，可「重练错题」或「返回大厅」 |
| 任务 | 查看家长布置的任务卡（含截止时刻），点「开始」进入答题；完成后显示「已完成」，被家长终止显示「已终止」 |
| 错题本 | 答错自动收录题目快照、错误答案和正确答案；支持「重练」（原题单题重练）和「掌握」（标记已掌握） |
| 绑定码 | 生成 6 位数字绑定码，**30 分钟内有效、只能成功使用一次**，供家长绑定 |
| 站内通知 | 任务布置等消息；显示未读数，支持单条已读和「全部已读」 |

答题过程中可以点右上角「END / 结束」主动结束本次练习。若是家长布置的任务，结束后任务会变成「已终止」，需要家长在任务管理页重新开放才能再练。

### 2.2 家长端（登录后进入「家长控制台」）

| 功能 | 说明 |
|---|---|
| 注册 / 登录 | 与学生共用账号体系，注册时选择「家长」，不填年级 |
| 绑定学生 | 在控制台输入学生生成的 6 位绑定码；已绑定学生会显示年级和昵称 |
| 我的学生 | 每个学生一张卡，可查看「结果」「分析」，也可解绑（解绑后不能再查看该学生历史结果） |
| 布置练习任务 | 选择学生、运算模式、难度、题数（5–100）、数值范围（滑杆 5–100，CUSTOM 可输入到 1000）、截止日期与时刻 |
| 已布置任务 | 默认只显示最近 3 条，点「MORE」进入任务管理页 |
| 任务管理（MORE） | 左侧是当前学生的答题分析，右侧是任务列表，可「修改」「结束」「重新开放」 |
| 结果列表 | 每次已完成练习一行：模式 · 难度、正确率、用时 |
| 学习分析 | 7 天 / 30 天两个口径：练习次数、总题数、正确率、总用时、各运算（加/减/乘/除）正确率 |
| 通知 | 学生完成任务、学生提前结束任务等消息；未读数显示在控制台 |

### 2.3 系统能力

- **角色与权限隔离**：Spring Security 区分 `STUDENT` / `PARENT`，家长只能查看自己当前已绑定的学生，学生只能访问自己的练习与错题。
- **题目快照**：开始练习时一次性生成全部题目并落库，之后只读；刷新页面、退出重进都不会换题。
- **服务端判分 + 幂等**：每道题只允许写入一条答案记录（数据库唯一键），重复提交不会刷分。
- **单进行中会话**：同一学生同时只能有一个 `IN_PROGRESS` 练习；如果还有没做完的练习，再进设置页会自动回到原来的答题页。
- **7 天有效期**：练习会话从开始起 7 天内有效，超时后需重新开始。
- **13 张数据表**：账号、绑定、任务、会话、题目、答案、错题、通知、PK、自检表齐全。

### 2.4 已有后端、但没有页面入口的能力（预留）

以下模块的数据库表、Service 和 API 已实现，但**当前前端没有入口页**，普通用户从界面上用不到：

| 能力 | 接口前缀 | 当前状态 |
|---|---|---|
| 全站排行榜 | `GET /api/leaderboard` | 返回前 50 名，按累计答对题数排序；无页面 |
| 异步 PK 挑战 | `/api/pk/**` | 6 位挑战码、双方共用题目、逐题判分；无页面 |
| 限时挑战 | `/api/practice/time-attack/**` | 固定 20 题 / 180 秒，每题 20 分；无页面 |

> README 的「主要功能」只把有界面入口的能力算作可用功能，避免把预留接口当成已完成产品。

### 3.1 技术栈

| 层次 | 组件 | 版本 |
|---|---|---|
| 运行时 | JDK | 17（JAR 字节码 major 61，JDK 17/21 均可运行） |

> 仓库不包含 `application.properties`：它含真实数据库密码，已被 `.gitignore` 排除。首次运行请复制模板并填写密码。

### 3.3 数据库表（13 张）

| 分组 | 表名 | 用途 |
|---|---|---|
| 账号与关系 | `users` | 学生/家长账号，手机号唯一，角色固定 |
|  | `binding_code` | 学生生成的一次性 6 位绑定码，30 分钟有效 |
|  | `parent_student_binding` | 家长-学生多对多绑定，`unbound_at` 为空表示有效 |
| 练习 | `practice_task` | 家长布置的任务（模式/难度/题数/范围/截止/状态） |
|  | `practice_session` | 一次练习会话与配置快照 |
|  | `practice_question` | 题目快照（题面、操作数、运算符、正确答案） |
|  | `practice_answer` | 逐题作答与服务端判分（每题一条，防重复） |
|  | `wrong_question` | 错题快照、错误答案、已掌握时间 |
| 通知 | `notification` | 站内通知与已读时间 |
| PK（预留） | `pk_challenge` / `pk_challenge_question` / `pk_challenge_answer` | 异步 PK 主表、共用题目、双方答案 |
| 自检 | `phase0_smoke_test` | 启动时写入/读取/删除一次，验证数据库可用；可安全删除 |

## 4. 安装方法

### 4.1 准备运行环境

| 依赖 | 要求 | 检查方式 |
|---|---|---|
| JDK | **17**（不能只用 JRE） | `java -version` 显示 `17.x.x` |
| MySQL | **8.x** | 服务 `MySQL80` 正在运行，或能连上 `127.0.0.1:3306` |

JDK 17 安装后需要配置：

```text
JAVA_HOME = C:\Program Files\Eclipse Adoptium\jdk-17.0.xx-hotspot
Path 追加 = %JAVA_HOME%\bin
```

改完环境变量要新开一个命令提示符再检查。

### 4.2 导入数据库（必须最先做）

**顺序很重要**：先导入 SQL，再启动 JAR。顺序反了会报 `Unknown database 'kids_math'` 或 `Table 'kids_math.users' doesn't exist`。

#### 方式 A：Navicat（推荐）

1. 连接本机 MySQL。
2. 菜单「文件」→「运行 SQL 文件」。
3. 选择 `database/init.sql`。
4. 编码选 `UTF-8` / `utf8mb4`。
5. 执行完成后刷新，应看到数据库 `kids_math` 和 13 张表。

#### 方式 B：命令行

在项目目录打开命令提示符：

```bat
mysql -u root -p --default-character-set=utf8mb4 < database\init.sql
```

输入 root 密码后等待完成。数据库不在本机时加 `-h` / `-P`：

```bat
mysql -h 127.0.0.1 -P 3306 -u root -p --default-character-set=utf8mb4 < database\init.sql
```

`init.sql` 包含：建库、`USE kids_math`、13 张表、外键/唯一索引/字符集，以及两个演示账号和一条家长-学生绑定关系（重复执行不会重复插入演示账号）。

### 4.3 创建并修改数据库配置

仓库提供 JAR 同级目录的 `application.properties.example` 模板，**不含真实密码**。先复制一份：

```bat
copy application.properties.example application.properties
```

然后用记事本打开 `application.properties`，只需要改这三行：

```properties
spring.datasource.url=jdbc:mysql://127.0.0.1:3306/kids_math?useUnicode=true&characterEncoding=utf8&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai
spring.datasource.username=root
spring.datasource.password=你的MySQL密码
```

- 数据库不在本机：把 `127.0.0.1` 改成数据库服务器 IP。
- 端口不是 3306：把 `3306` 改成实际端口。
- 模板里的 `CHANGE_ME` 必须替换成实际密码；密码为空时把等号右边留空。

> **注意**：`application.properties` 含真实凭据，已被 `.gitignore` 排除，不会出现在 GitHub 仓库。不要把填好的配置文件提交或上传；启动报 `Access denied for user 'root'@'localhost'` 时优先检查这里的用户名/密码。

### 4.4 启动

#### 方式 A：双击 `run.bat`（Windows）

> 运行前确认 JAR 同级目录已有 `application.properties`；如果是从仓库克隆，先按 4.3 复制模板。

脚本会切换到自身目录并执行：

```bat
java -jar kids-math-practice.jar --spring.config.additional-location=file:./application.properties
```

#### 方式 B：手动执行

在 JAR 所在目录打开命令提示符：

```bat
java -jar kids-math-practice.jar --spring.config.additional-location=file:./application.properties
```

启动成功的日志特征：

```text
Tomcat started on port(s): 8080 (http)
Started KidsMathApplication
```

启动窗口**不要关闭**，关闭即停止服务。

### 4.5 访问

浏览器打开：

```text
http://localhost:8080
```

或：

```text
http://127.0.0.1:8080
```

首页是项目落地页，右上角有「登录」「注册」。

### 4.6 局域网访问（手机 / 另一台电脑）

1. 在运行项目的电脑上执行 `ipconfig`，记下当前网卡的 IPv4 地址，例如 `192.168.1.23`。
2. 同一局域网设备访问 `http://192.168.1.23:8080`。
3. 打不开时依次检查：
   - 两台设备在同一个 Wi-Fi / 局域网；
   - `application.properties` 中有 `server.address=0.0.0.0`；
   - Windows 防火墙放行 Java 或 8080 端口；
   - 手机访问不要用 `localhost`，必须用电脑的局域网 IP。

### 4.7 改端口 / 停止

8080 被占用时：

```bat
java -jar kids-math-practice.jar --server.port=8081 --spring.config.additional-location=file:./application.properties
```

然后访问 `http://localhost:8081`。

停止：在启动窗口按 `Ctrl + C`。

## 5. 使用方法

### 5.1 首次使用：注册与绑定

1. 打开 `http://localhost:8080/register`。
2. 选择身份：
   - **学生**：填昵称、11 位手机号、密码（6–64 位）、确认密码、年级（1–6）。
   - **家长**：填昵称、11 位手机号、密码、确认密码；年级一栏隐藏且不参与提交。
3. 注册成功后回到登录页，用手机号 + 密码登录。
4. 学生登录后进入 `/student/binding-code`，点「生成」得到 6 位绑定码。
5. 家长登录后进入 `/parent/home`，在「绑定学生」处输入该码，绑定成功即可看到学生卡片。

> 演示用的 `DemoParent` 与 `DemoStudent` 在 `init.sql` 中已经绑定，导入后可直接登录家长端查看。

### 5.2 学生：自主练习

1. 大厅点「开始练习」进入设置页（`/student/practice/new`）。
2. 四个面板依次选择：
   - **运算舱**：混合 / 加法 / 减法 / 乘法 / 除法；
   - **难度**：L1 基础 / L2 进阶 / L3 挑战；
   - **题数**：滑杆 5–100；
   - **范围**：20 / 50 / 100（操作数与结果的上限）。
3. 点「START」开始，进入答题页。
4. 每题输入答案后提交；页面即时反馈对错，服务端判分并写入数据库。
5. 全部答完自动进入结果页，可「重练错题」或「返回大厅」。

如果中途退出，下次进设置页会提示「已有未完成练习，已为你继续」，直接回到原题；超过 7 天会提示已过期，需要重新开始。

### 5.3 学生：完成家长布置的任务

1. 大厅点「任务」进入 `/student/tasks`。
2. 任务卡显示：模式 · 难度、题数、截止时刻（若设置）、状态。
3. 点「开始」进入答题；如果还有别的未完成练习，会先继续那个。
4. 完成后任务卡显示「已完成」；家长端会收到完成通知。
5. 答题页右上角「END / 结束」可主动结束；任务会变成「已终止」，需要家长重新开放。

### 5.4 学生：错题本

1. 大厅点「错题」进入 `/student/wrong-questions`。
2. 列表按「未掌握优先」排序，显示题目、错误答案、正确答案。
3. 点「重练」会以原题创建一次单题练习，重新作答。
4. 点「掌握」标记为已掌握，之后排在列表后面（不会删除记录）。

### 5.5 家长：布置练习任务

1. 进入 `/parent/tasks`（控制台「布置练习任务」）。
2. 选择学生（绑定多个学生时有下拉框）、运算模式、难度、题数（5–100）、数值范围。
3. 数值范围：
   - 滑杆范围 5–100，随难度抬高下限：L1 5 / L2 10 / L3 20；
   - 点「CUSTOM」可输入 5–1000 的自定义上限，点「SET」生效。
4. 截止时间：
   - 点日历图标/输入框打开像素日历，先点日期数字选中某天；
   - 底部「TIME」用 ▲ / ▼ 调小时，分钟按 5 分钟步进；
   - 右侧「23:59」一键设为当日 23:59；
   - 点「确定」收起，输入框显示形如 `2026-11-17 20:30`；
   - 点「清除」表示不设截止时间。
5. 提交后，学生端任务卡和站内通知里会立刻出现该任务。

> 截止时刻不能早于当前时间。只选日期不选时刻时，按当天 23:59:59 截止；不选日期则不设截止。

### 5.6 家长：查看结果与分析

- **结果列表**：控制台学生卡片点「结果」→ `/parent/students/{id}/results`，每次已完成练习一行，显示模式 · 难度、正确率、用时。
- **学习分析**：点「分析」→ `/parent/students/{id}/analysis`，可切「7 天 / 30 天」，显示：
  - 练习次数、总题数、正确率、总用时；
  - 加法 / 减法 / 乘法 / 除法各自的正确率。

### 5.7 家长：任务管理（MORE）

1. 「已布置任务」面板只显示最近 3 条，点右上角「MORE」进入 `/parent/quests`。
2. 页面左侧是当前学生的答题分析：完成练习数、累计题数、整体正确率、近 7 天正确率、7 日柱状图、各运算正确率。
3. 右侧是任务列表，每条任务可：
   - **修改**：进入独立修改页，可改模式 / 难度 / 题数 / 范围 / 截止时刻；保存后任务重新开放给学生；
   - **结束**：任务置为已终止，学生端显示「已终止」，未完成会话会被关闭；
   - **重新开放**：把已终止任务恢复为待完成，学生可以再练一次。
4. 多个学生时可在页面上方切换学生。

修改任务时，服务端会校验：题数 5–1000，且不低于当前难度下限（L1 5 / L2 10 / L3 20），否则提示「当前难度至少需要 X 题」。

### 5.8 通知

- 控制台「未读通知」显示未读数，点「通知」进入列表。
- 通知来源：
  - 家长布置任务 → 学生收到「新的练习任务」；
  - 学生完成家长任务 → 家长收到「练习任务已完成」；
  - 学生提前结束任务 → 家长收到「学生提前结束了任务」。
- 支持单条「已读」和「全部已读」。

导入 `database/init.sql` 后可直接使用：

| 角色 | 手机号 | 密码 | 昵称 | 年级 |
|---|---|---|---|---|
| 学生 | `13900000901` | `demo1234` | DemoStudent | 3 |
| 家长 | `13900000902` | `demo1234` | DemoParent | — |

两者已建立绑定关系，登录家长端可直接看到 DemoStudent。演示账号仅用于本地体验，正式使用前请修改手机号/密码或删除。

### 5.10 规则速查

| 规则 | 实际行为 |
|---|---|
| 题数 | 练习/布置页滑杆 5–100；任务修改的服务端上限为 1000 |
| 数值范围 | 学生自练固定 20 / 50 / 100；家长页滑杆 5–100（难度下限 L1 5 / L2 10 / L3 20），CUSTOM 可到 1000 |
| 难度 | L1：一位数加减、表内乘除；L2：两位数不进位/不退位、一位数乘法、表内除法；L3：两位数进位/退位、两位数乘一位数、整除除法 |
| 截止 | 可选日期（默认 23:59:59）或日期 + 分钟时刻；不能早于当前；清除表示不设 |
| 单会话 | 同一学生同时只能有一个进行中练习；进入新练习会先继续旧的 |
| 有效期 | 练习开始后 7 天，超时需重新开始 |
| 用时 | 从开始到完成的总时长，包含中途停顿 |
| 判分 | 服务端判分；同一道题只记录一次答案 |
| 错题 | 答错即入错题本；可单题重练、可标记掌握 |
| 终止 | 学生 END 或家长「结束」都会终止任务/会话；需家长「重新开放」才能再练 |

## 7. 功能边界与已知限制

1. **本包只有可执行 JAR，不含源码**。页面模板、Mapper XML 和类都在 JAR 内；如果要改代码，需要另外拿到源码工程，改完后重新打包。
2. **PK / 排行榜 / 限时挑战没有前端入口**。数据表和接口存在，但当前版本的导航、学生大厅、家长控制台都没有链接进入，不能当作已完成功能验收。
3. **答题输入框限制 1–3 位数字（0–999）**。数值范围如果设为 1000，理论上可能出现答案 1000（4 位数），输入框无法提交；建议范围不超过 999，小学低年级用 20 / 50 / 100 即可。
4. **正确答案会随页面下发**，用于输入后的即时对错动画；最终成绩仍以服务端数据库判分为准。本项目适合家庭/局域网，不适合需要防作弊的公网考试场景。
5. **同一学生全局只能有一个进行中的练习**。学生如果还有没做完的自主练习，再点家长任务会先继续旧练习，而不是新开任务。
6. **启动日志中的 `[max-number] relaxed whitelist ...` 是正常现象**。JAR 启动时会通过 `MaxNumberWhitelistRelaxer` 把数值范围白名单放宽到 5–1000，方便自定义范围；不是报错。
7. **截止时刻补丁**：JAR 内 `com/example/kidsmath/task/TaskServiceDueTime.class` 是一个 `@Primary` 的 TaskService 子类。表单带 `dueTime` 时按分钟写入 `practice_task.due_at`；不带时保持原逻辑（当天 23:59:59）。
8. **`phase0_smoke_test` 是启动自检表**，每次启动会写入、读取、删除一条记录；不想保留自检可把 `application.properties` 中的 `app.phase0.db-smoke-test-enabled` 改为 `false`，业务表不受影响。

## 8. 常见问题

### 问题 1：`Access denied for user 'root'@'localhost'`

原因：`application.properties` 里的 MySQL 密码不对。
处理：改成安装 MySQL 时设置的 root 密码，重启项目。

### 问题 2：`Unknown database 'kids_math'`

原因：还没有执行 `database/init.sql`。
处理：先导入 SQL，再启动 JAR。

### 问题 3：`Table 'kids_math.users' doesn't exist`

原因：只建了库，没有建表。
处理：完整重新执行 `database/init.sql`。

### 问题 4：`Port 8080 was already in use`

原因：8080 被其他程序占用。
处理：

```bat
java -jar kids-math-practice.jar --server.port=8081 --spring.config.additional-location=file:./application.properties
```

### 问题 5：本机能访问，局域网不能访问

依次检查：

1. `application.properties` 中有 `server.address=0.0.0.0`；
2. Windows 防火墙放行 Java 或 8080；
3. 访问的是运行项目电脑的局域网 IP，而不是 `localhost`；
4. 两台设备在同一网络。

### 问题 6：页面中文乱码

- 导入 SQL 时加 `--default-character-set=utf8mb4`；
- Navicat 导入选择 UTF-8；
- 确认数据库字符集是 `utf8mb4`。

### 问题 7：启动后立即退出

用命令提示符运行以查看完整错误。常见原因：

- JDK 版本低于 17；
- 数据库密码/库名错误；
- 8080 被占用。

### 问题 8：登录后看不到学生 / 看不到任务

- 家长：确认已经用学生的 6 位绑定码完成绑定，且未解绑；
- 学生：确认任务未过截止时间、未被终止；
- 如果提示「已有未完成练习」，先完成或结束当前练习。

### 问题 9：修改任务时提示「当前难度至少需要 X 题」

修改任务的服务端规则：题数不得低于当前难度下限（L1 5 / L2 10 / L3 20）。把题数调高到下限以上即可。

### 问题 10：题数与设置不一致

通常是学生已有一个进行中的练习，系统自动恢复旧会话（题数按旧会话）。完成或结束后再开新练习即可。
